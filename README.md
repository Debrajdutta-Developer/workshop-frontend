# AI & Robotics Workshop Frontend

A React and TypeScript frontend for an AI and robotics workshop landing and registration experience.

## Tech stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Build and type-check

```bash
npm run build
npm run typecheck
```

## Environment configuration

Use the supplied `.env.example` as the reference for required configuration. Keep real credentials in local environment files or deployment secrets. Never commit live API keys, passwords, or private tokens.

## Status

This README describes the repository structure and declared toolchain. Backend integration, registration flows, and deployment status should be verified before presenting the project as production-ready.
